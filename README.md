# Avgeeks National ✈️

The home base of the Avgeeks National aviation channel: a sub tracker, airports, a 3D hangar, aviation games and a full flight sim with 28 real aircraft.

To put it online: Settings → Pages → Deploy from a branch → main / (root).

3D aircraft: Flightradar24 3D models, built from FlightGear aircraft (GPLv2) — see models/LICENSE-fr24.txt.
